Five ideas you'll see

Parameters (e.g. 3B)
The model's learned numbers. More parameters usually means better answers, but a bigger, slower model.
Quantization (Q4)
Storing each number in about 4 bits instead of 16, so the file is roughly 4 times smaller with a small quality cost.
RAM
The model must fit in your free memory while it runs. If it doesn't fit, it crashes or crawls.
Tokens per second
How fast it writes. A token is about three quarters of a word; people read about 5 per second.
Time to first token
How long you wait before the first word appears. Longer prompts make it longer.
