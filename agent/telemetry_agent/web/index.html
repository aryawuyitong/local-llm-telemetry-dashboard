Five ideas you'll see

Parameters (e.g. 3B)
The model's learned numbers. Size affects memory and computation; answer quality still needs evaluation.
Quantization (Q4)
Representing weights with fewer bits to reduce storage and memory. File size and quality depend on the exact artifact and method.
RAM
The model must fit in your free memory while it runs. If it doesn't fit, it crashes or crawls.
Tokens per second
Generated tokens divided by runtime-reported generation time. Tokens are text pieces whose size depends on language and tokenizer.
First-text latency
The wait until the first nonempty response text. A stream chunk can contain several tokens, so this is a proxy for exact TTFT.
